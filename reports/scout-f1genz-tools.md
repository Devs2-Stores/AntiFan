# SCOUT REPORT — F1GENZ Tools (E:\Work\apps\F1GENZ Tools)

## Project & Directory
Chrome MV3 extension v1.0.1 for Haravan theme developers. Upstream: github.com/F1GENZ/F1GENZ-Tools (branch main, held in nested `.git-nested/` repo — not a submodule). `.workspace-context.json`: kind=app, platform=haravan, branch=f1genz, components.extension=chrome-extension, verification=verified. ## Architecture & Role
Three execution contexts:
1. **content.js (ISOLATED world)** — injected on *.myharavan.com/*.haravan.com/web.haravan.app, all_frames. Gates injection by FORCE_EDITOR_HOSTS (web.haravan.app) or deep shadow-DOM editor-marker scan (.CodeMirror/.cm-editor/.monaco-editor/.ace_editor incl. shadow roots), then injects vendored lib/beautify{,-css,-html}.js + page-script.js into MAIN world via `<script src=chrome.runtime.getURL>` + web_accessible_resources. MutationObserver retries 15s for late-mounting editors. Pushes settings two ways: `data-f1genz-settings` URI-encoded JSON attribute on <html> AND `f1genz-settings` CustomEvents on window+document. Renders toasts via `f1genz-toast`. Injects "Làm đẹp" toolbar button (throttled 1/s, disconnects once placed).
2. **page-script.js (MAIN world, 1859 lines)** — editor abstraction over CM5/CM6/Monaco/Ace/textarea; beautify pipeline; Ctrl+B capture-phase keydown (capture:true fires before CodeMirror).
3. **popup.html/js** — Beautify tab (4 chrome.storage.sync keys) + Lint tab (paste code → lint report + auto-fixed output, persisted in chrome.storage.local).
background.js = empty onInstalled stub.

## Critical Edge Cases / Traps / Workarounds
1. **js-beautify tears Liquid inside <style>/<script>** — html_beautify delegates those bodies to css/js_beautify which split {{ x }} into {\n { x }\n}. Fix: protectInside('style'|'script') replaces every {% %}/{{ }} inside those blocks with ___LQ<n>___ placeholders before html_beautify, restores after; repairBrokenLiquidTags iterates ≤10 rounds re-joining already-torn tags. templating:['django']+indent_handlebars alone is NOT sufficient.
2. **CM6 has no DOM handle to its view** — resolved by scanning own property names AND symbols on .cm-editor/.cm-content elements, walking parentElement||getRootNode().host through shadow boundaries.
3. **CM6 full-doc replace loses viewport** — restored via line/col of anchor+head, top-viewport line, pixel offset via coordsAtPos, re-applied across triple rAF + 0/50/150ms timeouts (CM6 relayouts async).
4. **Isolated↔Main comms** — CustomEvents work both directions; data-f1genz-settings attribute is the reliable channel (event timing races injection order).
5. **settings.html detection is heuristic** — filename OR <fieldset>+<tr> co-occurrence; non-settings file with fieldsets gets tr-compaction (accepted false-positive).
6. **Drift/dead code**: README advertises Ctrl+C clipboard-beautify (no copy listener exists) and GitHub auto-update (background.js empty stub; version.json 1.0.0 vs manifest 1.0.1). Gemini host_permission unused. .hcb-init-settings-btn CSS dead. .antigravity/mcp-bridge/*.res.json residue shows AntiFan bridge writes artifacts into project dirs.

## Improvements for Super Core
- **platform_semantics (haravan)**: no {% schema %} block (Shopify-ism) — settings live in settings.html (legacy table/fieldset) or settings_schema.json (F1GENZ); settings[dynamic] requires {% capture %}/{% assign %} key first — string concat inside brackets fails parser; theme editor iframe-hosted at web.haravan.app running CM5 or CM6; {% form 'contact' %}, {% paginate %}, {% tablerow %} valid block pairs; product.metafields.hrvptabs.tabs uses @@###@@ tab / @@##@@ title-content separators.
- **anti_patterns**: (a) generic html/css/js beautifier directly on Liquid source — tears {{ }}/{% %} inside style/script; (b) self-closing non-void tags <textarea/>, <div/>; (c) settings[key + var] dynamic access; (d) Liquid syntax inside settings.html (pure-HTML contract); (e) flat SCSS nesting ignoring DOM hierarchy.
- **fix_patterns**: placeholder-protect → transform → restore for mixed-language source; iterative torn-tag repair (\{\s*\{(-?)([^{}]*?)(-?)\}\s*\} → {{ }}); structural fingerprint abort (count invariants before/after transform); two-pass idempotency check.
- **workarounds**: MAIN-world injection via web_accessible_resources (isolated world can't see CodeMirror); CustomEvent + data-attribute dual channel for cross-world settings; CM6 view discovery via own-props+symbols scan walking shadow hosts; MutationObserver-gated lazy attach with bounded lifetime (15s).
- **tool_intel**: js-beautify templating:['django'] + indent_handlebars:true partially preserves Liquid but still corrupts tags inside <style>/<script> — pre-protection mandatory.
