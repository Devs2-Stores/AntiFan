# Ultra Scout Report — antigravity-browser

## 1. Project & Directory
`E:\Work\apps\antigravity-browser` — VS Code/Antigravity IDE extension "Antigravity Web Browser" v2.0.1 (publisher `antigravity`). TypeScript → `out/` (commonjs, ES2021, strict). Zero runtime deps. Ships as VSIX (`antigravity-browser-2.0.0.vsix`, `.dev-build-2.0.1.vsix`). Layout: `src/` (14 files), `out/` compiled + vendored assets, `mcp-server.mjs` standalone MCP server, `sidecars/antifan-chat-router/` (router.mjs + lib/agentapi.mjs + sidecar.json), `test/` (12 .cjs suites), `scripts/` (install-sidecar, probe, watch, package-team), `plans/` (3 plans + 6 reports), `bin/ag-screen-capture-x64.exe` (orphaned), `.antigravity/` live bridge/annotation state.

## 2. Architecture & Role
Embedded live browser inside a VS Code WebviewPanel — NOT CDP. The real page runs in an `<iframe>` whose src is a localhost rewriting proxy; all cross-origin isolation is defeated by serving everything from `http://127.0.0.1:<port>`.

Pipeline: `extension.ts` (activate → LocalBrowserProxy + BrowserRuntime + DesktopCommandBridge + MCP registration) → `browserPanel.ts` (webview shell, nonce CSP `frame-src http://127.0.0.1:*`, token/port/session placeholders) → `webview.html` (2279 lines: tab strip, omnibox, per-tab session/history/zoom/device-width, postMessage router) → `proxyServer.ts` (1072 lines: token+HMAC auth, bootstrap 302, DNS-pinned SSRF guard, cookie jar, HTML rewrite + inspector injection) → `inspectorScript.js` (2212 lines injected into every page: fetch/XHR rewrite, link/history hooks, inspect/font/ruler overlays, SnapDOM capture, MCP click/evaluate) → `runtime.ts` (annotation → `.antigravity/annotations/*.md` + snapshots → `sendToAgentPanel` handoff) → `desktopCommandBridge.ts` (file-bus consumer for AntiFan desktop `cmd-*.json` v2 protocol) → `sidecarRouterClient.ts` → detached `sidecars/antifan-chat-router/router.mjs` → `agentapi send-message <conversationId>`.

Relation to AntiFan: this is the IDE-side counterpart of AntiFan Desktop. AntiFan writes `AntigravityCommandV2` files into `<workspace>/.antigravity/mcp-bridge/` (contract mirrored in `AntiFan/src/shared/contracts.ts:110`); the extension claims them, routes `send-prompt` to Antigravity Chat via `vscode.antigravityExtensibility.sendToAgentPanel`, or to an exact conversation via the sidecar→agentapi path. AntiFan's own annotations use `capture_method: electron-capturePage` (compositor pixels) vs this extension's `snapdom` (DOM reconstruction) — two different evidence classes sharing one annotation envelope.

## 3. Load-bearing Files & Contracts

**proxyServer.ts** — `LocalBrowserProxy`:
- Auth: 64-hex token persisted at `<globalStorage>/proxy-auth-token` (atomic link, mode 0600, `loadOrCreateProxyToken` L37). `/bootstrap?token&session&url` → 302 to `/proxy?session&auth=<HMAC(session,token)>` + sets `__ag_token` + `__ag_session_<sha256(session)[:16]>` HttpOnly SameSite=Strict cookies (L443-475). Every later request needs token OR session-auth cookie (L490-505).
- SSRF guard: `resolveTargetAddress` (L1040) DNS-resolves all addrs, rejects mixed public/private, `createPinnedLookup` pins the resolved IPs into the outbound request (L1053). Session origin lock: `sessionOrigins` map (100 entries, 2h TTL); non-same-origin requests 403 unless public→public non-document subresource (L590-610). Cross-origin document redirect → synthetic HTML with `__AG_TRUSTED_REDIRECT__` + inspector (L755-770).
- Header stripping: deletes x-frame-options, CSP (+report-only), COOP/COEP/CORP, permissions-policy, clear-site-data; forces `referrer-policy: no-referrer-when-downgrade`; deletes upstream set-cookie into jar (L715-740).
- HTML rewrite (L790-880): buffers ≤10MB, decompresses gzip/deflate/br, strips meta CSP, masks `<script|style|textarea|template>` raw-text via `__AG_RAW_<hex>_<i>__` placeholders, rewrites `href|src|action|poster` attrs + root-relative `srcset` entries to `/proxy?session&auth&url=`, special-cases `/password` forms (Haravan storefront password page), injects `<base href=real-url>` + `__AG_TARGET_URL__`/`__AG_PROXY_PORT__`/`__AG_PROXY_AUTH__` + anti-frame-bust (`window.top` getter → self) + inspector `<script src=...?session&auth>`.
- `SimpleCookieJar` (L62-260): partitionKey=session, full domain/hostOnly/path/secure/sameSite/max-age semantics, `SameSite=None` requires Secure, Lax+top-level-GET allowed, persisted plaintext `browser_cookies.json` v4. `siteKey()` uses a ~40-entry hardcoded multi-label public-suffix set (L270).
- Impersonation: forces Chrome 133 UA + sec-ch-ua when incoming UA matches /electron|code\/|vscode/i (L640); synthesizes sec-fetch-* (document→navigate/none/?1, else cors/same-origin, then recomputed same-origin/same-site/cross-site vs sessionOrigin L660-700); `accept-language: vi-VN,vi;q=0.9,...` default.
- Serves `/__antigravity_inspector.js`, `/__antigravity_snapdom.js`, `/__antigravity_pixelmatch.js` from extension assets with ACAO:* (still auth-gated).

**webview.html** — tabs as objects `{id, session, url, documentGeneration, historyStack/Index, bridgeCapability, hostCapability, zoom, deviceWidth}`; iframe per tab at TRUE device CSS width, visual fit = CSS transform scale (media queries see real width — correct emulation). Capability handshake: on iframe load, parent posts `ANTIGRAVITY_BRIDGE_REQUEST {capability: hostCapability}`; inspector replies `ANTIGRAVITY_BRIDGE_READY {capability: bridgeCapability}`; all page→host messages require `msg.capability === tabObj.bridgeCapability` (L1797-1807) and host→page messages carry hostCapability checked by `isAuthorizedParentMessage` (inspector L65). `documentGeneration++` on every navigation/location change → staleness fence for queued annotations (L1892-1903). `postToTab` returns false silently when bridgeCapability unset (L581-588).

**inspectorScript.js** — wraps `window.fetch` + `XHR.open` to route through `/proxy` (L205-245); namespaces `localStorage` per target host `__ag_ls_<host>_` (L250-300); hooks `history.pushState/replaceState` + popstate/hashchange → `ANTIGRAVITY_LOCATION_CHANGED`; captures clicks on `a, area` → `ANTIGRAVITY_NAVIGATE_TO` / `ANTIGRAVITY_OPEN_TAB` for `_blank` (L2160-2180); collects runtimeErrors/unhandledrejection/resourceFailures (last 20) + slowResources >500ms; `executeMCPCommand` supports `click` (virtual cursor animation + dispatched mousedown/mouseup/click), `evaluate` (raw `eval`, awaitPromise, depth-3 serializer), `visualDiffCapture` (SnapDOM body clip) (L857-910); SnapDOM capture chain with 5s timeout, image-decode safe-mode excluding img/video/canvas, viewport-crop fallback ladder emitting captureWarnings (L1100-1250).

**runtime.ts** — `handleWebviewMessage` dispatch (~20 commands); `processAnnotationPayload`/`processMultiElementsPayload` build evidence-envelope Markdown (annotationId, sourceRevision `document:<session>:generation:<n>`, captureMethod, evidenceStatus complete|partial, terminalState) → writes `.antigravity/annotations/element_<ts>.md` + PNG snapshots (PNG magic validated, ≤8MB target/12MB viewport) → `handoffToAntigravityChat` single-flight with 15s stall warning + 30s hard deadline + clipboard copy + `vscode.open` fallback (L770-850). `cleanupOldSnapshots` deletes files >30min in BOTH annotations/ and snapshots/ (L880). `executeMCPCommand` (L206-284) routes `sendToAgentPanel`/`abortTurn` else posts `mcpExecute` to webview with 12s timeout — **no callers: dead code**.

**desktopCommandBridge.ts** — per-workspace `.antigravity/mcp-bridge/`: host.json heartbeat 3s (capabilities: send-prompt/abort, draft/auto, 8 attachments, 15MB), poll 250ms, `cmd-*.json` → validateCommandV2 → workspace-ownership guard (exact or child path; reverse-child allowed only for exact-auto) → idempotency via `.res.json` → expiry → atomic rename claim `.processing.<host>.json` → execute ≤29s (`EXTENSION_COMMAND_DEADLINE_MS`) → signed result. Exact-auto (`mode=auto` + `targetConversationId`) → SidecarRouterClient.dispatchExact, fail-closed `EXACT_ROUTE_UNAVAILABLE` when sidecar offline; `abort`+conversationId → `EXACT_ABORT_UNSUPPORTED`. `unknown` results get late reconciliation pass (L420-448). Stale `.tmp-`/`.processing.` >5min and all files >24h cleaned.

**sidecarRouterClient.ts + router.mjs + agentapi.mjs** — sidecar data dir `~/.gemini/antigravity/sidecar_data/antifan-chat-router/data` (shared across workspaces); auth.key 32B mode-0600; request = canonical-JSON (sorted keys minus authTag) HMAC-SHA256; receipt verified timingSafeEqual + id/sourceCommandId/conversationId binding; `bindingVersion 2` requires projectId/workspaceId/attemptId/backendSessionRef. Router: single-flight FIFO (sorted entries), processing-dir crash recovery (`isInvoking` → `CRASH_DURING_INVOCATION` unknown vs `CRASH_BEFORE_INVOCATION` failed), completed-dir idempotency, spawns `agentapi send-message <convId> <prompt + "Attachments: @[file://...]">` with `shell:false`, Windows `.bat/.cmd` wrapper unwrapped by parsing `%*` line (agentapi.mjs L88-100), timeout kill via `taskkill /pid /T /F`. Deadline chain: agentapi 25s → extension 29s → desktop caller 34s (`transport-timeouts.ts`).

**mcp-server.mjs** — standalone JSON-RPC stdio MCP (registered via `antigravityExtensibility.writeMcpConfig`, `ELECTRON_RUN_AS_NODE=1`): 12 tools (9 read-only capture/manifest/validate/compare + `navigate`/`click`/`evaluate`), 4 resources + 2 templates, 3 prompts (qa/fix/review). `bridgeCommand()` writes `{id, action, params, at}` to `.antigravity/mcp-bridge/cmd-*.json`, polls `.res.json` 25s.

**annotationPrompt.ts** — `AGENT_CONTRACT_VERSION 2.0.0`: STANDALONE_AGENT_CONTRACT (Gates 0-5, scope lock, OBSERVED/DERIVED/PRIOR/ASSUMED labels, terminal states READY/BLOCKED/DECISION REQUIRED/PARTIAL/FAILED) + 20 intent modules + tweak classifier (TWEAK_PROPERTY_PATTERN vs scope-expand pattern).

## 4. Critical Edge Cases / Traps / Workarounds

1. **BROKEN: MCP navigate/click/evaluate silently dead.** `mcp-server.mjs:139` writes `{id, action, params}` with NO `protocolVersion`; `desktopCommandBridge.ts:209` requires `protocolVersion === 2` → file ignored forever → 25s "delivery is unknown" timeout. `runtime.executeMCPCommand` (the only path that would post `mcpExecute` to the webview) has zero call sites. The whole live-tab MCP toolchain is unreachable; only the file-based read tools work.
2. **Password-form heuristic over-fires** (proxyServer L855-865): any `<form>` without action on a page containing `name="password"` gets `action=/password` — correct for Haravan/Sapo storefront password pages, wrong for any other password form (login, signup, account).
3. **Cross-origin iframes are dead**: session-origin lock 403s non-public or document cross-origin requests; a public cross-origin document redirect hijacks the TOP tab via `__AG_TRUSTED_REDIRECT__`. YouTube/maps/payment embeds cannot render inside a proxied page.
4. **srcset rewrite only handles root-relative `/` URLs** (L840): absolute `https://cdn...` and protocol-relative `//` entries bypass the proxy → mixed-content/CSP-referrer leaks and broken images. `url()` in inline styles/CSS, `srcdoc`, meta refresh, `data-*` URL attrs, `navigator.sendBeacon`, `WebSocket`, `EventSource` are all unrewritten — WS/SSE connect directly to real origin (works, but bypasses cookie jar/session and leaks the proxy).
5. **Cookie jar plaintext** at globalStorage `browser_cookies.json` — session tokens for every browsed site in cleartext; `sessionStorage` is NOT namespaced (only localStorage is) → leaks across navigated sites within a tab.
6. **30-min TTL self-destructs evidence**: `cleanupOldSnapshots` deletes annotation .md + PNGs while an agent turn may still reference them; `latest_element_mcp.json` keeps markdownContent but `read_capture`/image tools then fail.
7. **postToTab silent drop**: if inspector fails to load (CSP edge, script error, non-HTML), `bridgeCapability` stays null → every host→page message (inspect toggle, MCP command, annotation result) silently returns false; no error surfaces.
8. **Deadline skew**: mcp-server hardcodes `BRIDGE_TIMEOUT_MS=25000` < extension's 29000 command deadline — caller gives up 4s before callee's own timeout; transport-timeouts.ts exists precisely to prevent this but mcp-server.mjs doesn't use it.
9. **Capability token is page-readable**: `hostCapability` is posted to the iframe contentWindow; page JS can capture it from the message event and forge `ANTIGRAVITY_*` messages to the parent (e.g., fake NAVIGATE_TO → open phishing URL in a new tab; fake ELEMENT_SELECTED → inject annotation). Page→host direction is protected (bridgeCapability never sent down), host→page is not.
10. **eval() in inspector** runs in page main world — page can patch `eval`/`Function` or read `window.__AG_*` globals; MCP evaluate is detectable/poisonable by the target page.
11. **window.top override** (`Object.defineProperty(window,'top',{get:()=>self})`) breaks legitimate frame-ancestry checks and any page code relying on `top !== self`.
12. **Network-class lock**: if a session's origin re-resolves to a different network class (failover/CDN), every request 403s "Target network changed"; private→public transitions impossible mid-session.
13. **Stale artifacts**: `out/nativeCapture.js` + `bin/ag-screen-capture-x64.exe` (removed native-capture feature; .vscodeignore excludes both but they sit in tree), `out/vendor/` empty dir, `pixelmatch.min.js` served by proxy but never loaded by inspector (dead asset), `isSafeBridgeId`/`writeJsonAtomic`/`executeMCPCommand` dead in runtime.ts, `pixelmatch.index.js` unreferenced ESM source.
14. **`.gitignore` auto-mutation**: `getStorageDirectory` appends `.antigravity/` to workspace .gitignore without asking (runtime L390).
15. **Activation too broad**: `workspaceContains:**/package.json` activates in every JS workspace → bridge creates `.antigravity/mcp-bridge/` + host.json heartbeat in all of them (evidence: stale cmd/res files across customizes/* and apps/* trees).
16. **Unclaimed commands are indistinguishable from loss**: dozens of `cmd-*.json` (1.8-1.9KB, 53 lines, v2 shape) sit unclaimed in other workspaces' mcp-bridge dirs — when the extension isn't running in the target workspace, the desktop's command just rots; producer has no liveness signal beyond host.json heartbeat staleness.
17. **Google sorry-redirect hack**: redirects to `/sorry/index` are rewritten to bing.com search preserving `q` (L745) — works, but silently changes the destination origin.
18. **HTML 10MB cap** destroys the response mid-stream (`targetRes.destroy`) → truncated page, no clean error.
19. **Sidecar spawn is Windows-hardcoded**: node candidates are `C:\Program Files\nodejs\...` + nvm path; non-Windows falls back to bare `node`. `ensureSidecarRunning` swallows all spawn errors → `SIDECAR_OFFLINE` later.
20. **SnapDOM evidence ≠ pixels**: captureWarnings already flag canvas/video/iframe/pseudo-elements; AntiFan desktop annotations use `electron-capturePage` — same envelope, different fidelity class; consumers must branch on `capture_method`.

## 5. Concrete Improvements for Super Core

**Anti-patterns to record:**
- AP: "File-bus protocol version skew → silent drop." Producer/consumer version mismatch MUST emit an explicit error receipt (`UNSUPPORTED_PROTOCOL_VERSION`), never ignore the file — the v2 bridge silently drops legacy cmd files, and the mcp-server's own commands are currently dropped the same way. Any file-bus consumer should reject-and-receipt unknown versions.
- AP: "Hardcoded timeout literal drifting from the shared deadline chain." mcp-server.mjs:133 `25000` vs transport-timeouts.ts chain 25s/29s/34s. Rule: caller deadline = callee deadline + transport buffer, single source of truth.
- AP: "DOM-reconstruction screenshot presented as pixel evidence." SnapDOM/html2canvas class output must always carry `capture_method` + fidelity warnings; never label it compositor capture. (Already enforced here via captureWarnings — codify as rule.)
- AP: "Regex HTML URL rewriting as a completeness boundary." Enumerate the uncovered surface (absolute srcset, //, url(), srcdoc, meta refresh, sendBeacon, WS, SSE, dynamic import) — a rewriter that claims full coverage without this list is a trap.
- AP: "postMessage 'capability' sent INTO the untrusted frame." Any token delivered to page context is page-readable; direction matters — secrets only ever flow page→host, never host→page.
- AP: "Evidence TTL shorter than consumer turnaround." 30-min cleanup vs multi-minute agent runs → PARTIAL/stale evidence mid-flight. TTL must exceed max consumer SLA or be lease-renewed.

**Fix patterns:**
- FP: atomic-claim file queue = `rename(cmd → cmd.processing.<instanceId>)` + tmp-write+rename receipts + idempotency via existing `.res.json` + crash recovery distinguishing pre-invocation (failed) vs mid-invocation (unknown). Proven in both desktopCommandBridge and router.mjs.
- FP: HMAC canonical-JSON receipts (sorted keys minus authTag, timingSafeEqual, field-binding check id+sourceCommandId+conversationId) — the sidecar request/receipt pair is the reference implementation.
- FP: DNS-pinning SSRF guard = resolve-all → reject mixed-class → custom `lookup` returning pinned addresses + network-class change detection per session.
- FP: staleness fence via monotonic `documentGeneration` incremented on every navigation; queued work items carry the generation and are rejected when it moves (webview L1892).
- FP: single-flight handoff with stall-warning + hard deadline + reset escape (runtime handoffToAntigravityChat 15s/30s).
- FP: Windows .bat/.cmd shim unwrapping by parsing the `%*` line to spawn the real executable with `shell:false` (agentapi.mjs) — avoids cmd.exe prompt-injection; plus `taskkill /pid /T /F` for tree kill.

**Platform semantics:**
- VS Code webview CSP `frame-src http://127.0.0.1:*` ⇒ the ONLY embedded-browser architecture is a localhost rewriting proxy + iframe; CDP is unavailable to extension webviews (plan docs confirm CDP was deliberately removed).
- `vscode.antigravityExtensibility.sendToAgentPanel` resolves on IDE-API acceptance, NOT agent submission — `ide-api-accepted` ≠ delivered; autoSend default is true; `queue/queueIfRunning/sendToQueue` flags exist.
- `SameSite=None` requires Secure — the jar mirrors Chrome; apps omitting Secure silently lose cookies.
- agentapi conversation IDs match `~/.gemini/antigravity-ide/brain/<conversation-id>` directory keys.

**Workarounds:**
- WA: storefront password page — rewrite action-less forms to `/password` when page contains `name="password"` (Haravan/Sapo specific, over-fires elsewhere).
- WA: Google `/sorry/index` captcha redirect → rewrite to bing search preserving `q`.
- WA: per-host localStorage namespacing `__ag_ls_<host>_` when all origins collapse to 127.0.0.1.
- WA: raw-text masking (`__AG_RAW_<hex>_<i>__`) before regex rewriting so script/style/textarea/template contents aren't mangled.
- WA: trusted-redirect bootstrap page for cross-origin document redirects (carries expectedNetworkClass through the proxy boundary).

## 6. Concrete Improvements for Haravan Theme Core Output

1. **Preview/QA environment contract**: when ThemeCompiler output is QA'd inside this browser, cross-origin embeds (YouTube, Google Maps, payment/3DS iframes, social widgets) 403 or hijack the tab — DoD/QA must classify these as environment limitations, not theme defects. Add a "proxied-preview unsupported surface" list to the QA validator.
2. **Storefront password page**: the `/password` rewrite heuristic exists because Haravan/Sapo password forms post to `/password` — ThemeCompiler should emit the form with explicit `action="/password"` so it survives both proxy and direct browsing; never rely on empty action.
3. **Cookie behavior parity**: the jar enforces real SameSite/Secure/path semantics — theme/app features depending on `SameSite=None` without Secure will fail in preview exactly as in Chrome; settings contract should document this.
4. **URL-resolution fidelity**: theme JS reading `a.href`/`script.src` sees proxy URLs; the inspector patches the getters to reveal real URLs — DOM dumps/sanitizers should normalize `127.0.0.1:<port>/proxy?...&url=<real>` back to `<real>` (unwrapProxyUrl pattern, inspector L2140) and treat `window.__AG_TARGET_URL__` as canonical page URL.
5. **Viewport emulation is transform-based**: innerWidth/media queries are truthful, but `devicePixelRatio`, `screen.*`, and compositor-level zoom are host values — responsive QA claims from this surface must tag `emulation: css-transform`.
6. **Evidence envelope reuse**: the annotation envelope (annotationId, sourceRevision `document:<session>:generation:<n>`, captureMethod, evidenceStatus, terminalState) is a ready-made schema for ThemeCompiler's capture manifests and HaravanSchemaGenerator's settings-contract provenance — adopt the same field names so Super Core claims can join across tools.
7. **AJAX/delegated clicks preserved**: tests prove delegated AJAX links stay AJAX under the proxy — theme JS intercepting clicks works; but `history.pushState` hooks must be expected (inspector patches them).

## 7. Concrete Improvements for AntiFan Core & Site Clone

**AntiFan Core:**
- Adopt the `deliveryState` vocabulary verbatim for verification claims: `queued | ide-api-accepted | failed | unknown` — especially `unknown` for deadline-exceeded/crash-during-invocation (never retry an `unknown` blindly; reconcile first via `reconcileLate`).
- Reuse the exact-route fail-closed pattern: `EXACT_ROUTE_UNAVAILABLE` when the precise target can't be honored beats silent fallback to broadcast — AntiFan's tab-binding/authority-rotation should refuse rather than approximate.
- The bridge heartbeat+capabilities doc (host.json: actions, modes, maxAttachments, maxPayloadBytes, extensionVersion) is the model for AntiFan's own capability advertisement; include version so peers can gate features.
- Fix the broken MCP live-tool path before relying on it: either emit v2 commands from mcp-server.mjs or re-add a legacy consumer; today `antigravity_browser_navigate/click/evaluate` always time out — AntiFan must not treat them as a working control channel.
- Generation-fence pattern (documentGeneration + sessionId + tabId + pageUrl quadruple) is directly applicable to AntiFan's stale-tab/stale-surface rejection.
- `agentHandoffInFlight` single-flight + user-facing stall warning + reset option is the proven UX for any blocking handoff.

**Site Clone:**
- Coverage checklist for the asset pipeline/IR extractor — the proxy's rewrite surface shows exactly what a cloner must handle: href/src/action/poster attrs, srcset (ALL forms: root-relative, absolute, protocol-relative — the proxy only does root-relative, a known gap), CSS `url()` (inline + stylesheet), srcdoc, meta refresh, form actions, dynamic script/link injection (needs runtime hook like the fetch/XHR wrap), WS/SSE/sendBeacon (decide: proxy, stub, or document as live-only).
- Cookie/session offline model: `StoredCookie` (partitionKey, hostOnly, path, secure, sameSite, expiresAt, createdAt) is a complete offline-replay schema; `siteKey()` needs a real PSL for correctness — the 40-entry hardcoded list is the documented shortcut.
- Raw-text masking before rewriting (script/style/textarea/template) — mandatory ordering step for any HTML transformer; restores after attr rewrite.
- Trusted-redirect bootstrap = the pattern for offline standalone navigation: intercept cross-origin doc navigations, resolve through a bootstrap that re-binds session state instead of leaking cookies or 403ing.
- Resource bounds for the fetcher: 10MB HTML cap, 30s upstream timeout, 100-entry session-origin map with TTL — concrete DoD validator limits.
- SSRF test suite for clone fetch: `isPrivateAddress` covers IPv4 (0/8, 10/8, 100.64/10, 127/8, 169.254/16, 172.16/12, 192.168/16, 198.18/15, ≥224) + IPv6 via bigint (::/128, ::1, fc00/7, fe80/10, ff00/8, v4-mapped) — reuse as the clone fetcher's blocklist oracle.
- DoD validator: PNG evidence validation = signature + IHDR + width/height + sha256 (mcp-server.mjs `pngMetadata`); byte-diff comparison (`comparePngFiles`) is the deterministic baseline for offline-vs-live parity checks — pixelmatch is vendored but unused, available for pixel-level diff.

**Repo hygiene flags:** dead code — `runtime.executeMCPCommand` + `pendingMCPResults` path (uncalled), `isSafeBridgeId`, `writeJsonAtomic`, `out/nativeCapture.js`, `bin/ag-screen-capture-x64.exe`, `out/vendor/` empty, `pixelmatch.min.js` served-but-unused, `pixelmatch.index.js` orphan. Test suite uses global `WebSocket` (needs Node ≥21 for the CDP integration tests; skips gracefully without Chrome).
