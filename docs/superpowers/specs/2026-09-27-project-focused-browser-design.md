# Project-focused browser design — superseded

Status: superseded on 2026-09-27; not an implementation authority.

The original direction used one browser window with a project-filtered tab strip. The user subsequently confirmed a requirement to view different projects simultaneously on separate monitors and selected one window per project with a shared runtime.

The replacement specification is [Project Windows for solo local development](2026-09-27-project-windows-design.md). Use it for implementation planning. The earlier five-candidate ultra review rejected all candidates and must not be cited as certification of the selected architecture; the decision followed the user's additional workflow evidence.

This path remains as a supersession record so previous links do not silently refer to a different architecture. No product behavior was implemented by changing these documents.
