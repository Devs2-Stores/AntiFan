## Per-proof assertion

1. **Two project windows on distinct owners, each with its own terminal set** —
   driver row `terminal.two-project-windows-hold-their-own-scopes` asserts
   `betaEntry.ownerKey !== alphaKey`, `browserShellCount() === 2` with both projects open, and that each
   window's own `listTerminals()` contains the session it minted and not the other's, cross-checked
   against `TerminalManager.sessionOwnerKey(id)`.
2. **A manager-minted terminal assigned to capsule X through the real invoke** —
   row `terminal.manager-assigns-session-through-ipc` calls
   `window.antifanStandalone.assignTerminalCapsule(sessionId, capsuleId)` on the manager window's own
   sidebar (the real `TERMINAL_CHANNELS.ASSIGN_CAPSULE` invoke) and asserts the reply is
   `{ok:true, sessionId, capsuleId, ownerKey:'project:<X>'}` plus the manager's own stamps
   (`sessionOwnerKey`, `sessionCapsuleId`).
3. **The session appears in X's window and leaves the previous window, manager still sees it** —
   row `terminal.assignment-moves-session-scope` asserts the target window's list gains the row, the
   window it was taken from loses it (`previousOwnerListed === false` after a `waitForRowGone` poll),
   and the manager still lists it; the second half moves a project-minted session to a foreign capsule
   and checks the same three directions.
4. **A closed target's window opens first, then the session is present there** —
   row `terminal.assign-opens-closed-target-window` first asserts the refusal
   `{ok:false, reason:'TARGET_WINDOW_ABSENT'}` leaves the owner stamp and the manager's row untouched,
   then drives the renderer's own flow (`openProject` → `{status:'OPENED'}`) and asserts the assign is
   accepted and the newly opened window's list contains the session.
5. **A caller naming no window is still refused** — rows
   `terminal.window-less-chrome-caller-refused` (a real renderer carrying the shipping standalone
   preload, owned by no shell: the invoke rejects, the message names the refused channel and the
   sending surface, and `dispatchChromeRoute` re-refuses it with the router's own
   `UnknownChromeSenderError` class) and `terminal.window-less-mcp-caller-refused` (a real
   `AntiFanMcpServer` over the runtime's own `controlPlane.transport`: `ATTACHMENT_REQUIRED` with no
   attachment, `TERMINAL_FORBIDDEN` for an attachment bound to no tab), both asserting no session id
   appears in the refusal text.

## Notes and design decisions

- **Manager window**: no chrome route opens the Unassigned window (the user reaches it through Main's
  own surface), so the probe uses `projectWindowAuthority.ensureProjectWindow({kind:'unassigned'},'user')`
  — the same factory a user open runs — and proves it was closed before the row (`entryFor('unassigned') === null`).
- **Session scopes** are read from each window's own preload (`listTerminals()`), i.e. the same
  `visibleTerminalSessions(sender)` projection the sidebar bootstraps from; owner stamps are read in-process
  from `TerminalManager`, so a scope that agreed by accident is still visible.
- **Refusal codes asserted** are producer-owned wire codes read from the shipping code
  (`TARGET_WINDOW_ABSENT`, `ATTACHMENT_REQUIRED`, `TERMINAL_FORBIDDEN`); refusal *sentences* are recorded
  in evidence, not asserted, so wording changes do not fail the lane.
- **Cleanup**: the driver closes every session it minted, closes every shell it opened
  (`requestClose` per snapshot entry, waiting for `browserShellCount() === 0`), destroys the
  out-of-factory caller window, and removes only its own `mkdtemp` roots (guarded by a name prefix).
  The only wall-clock timer in the test file is the `RUN_TIMEOUT_MS` watchdog on the spawned child, which
  kills that child only (its own PID, tree flag); every wait inside the scenario polls for the state
  under test instead of sleeping for a guessed duration.
- **Evidence** is written to a per-run temp directory (not into the repo), and a failing assertion quotes
  it in the failure message so the run's own receipt survives the temp cleanup.
